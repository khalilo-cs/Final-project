# ضاد — دعم VS Code

دعم كامل للغة البرمجة العربية **ضاد** داخل VS Code:

- **تلوين الصياغة** للكلمات المفتاحية والدوال المدمجة والوحدات والأرقام الشرقية والغربية.
- **تشخيص فوري** أثناء الكتابة بأكواد أخطاء موثقة (`ضاد-1003`…) واقتراحات إصلاح.
- **إكمال تلقائي** عربي: الكلمات المفتاحية بمقتطفات، أعضاء الوحدات بعد النقطة، واستيراد تلقائي للوحدة.
- **تلميحات** تعرض توقيع الدالة وتعليق التوثيق `##`.
- **الانتقال إلى التعريف، المراجع، إعادة التسمية، ومخطط المستند.**
- **مساعدة التوقيع** تعمل مع الفاصلة العربية `،`.
- **إصلاحات سريعة**: تصحيح اسم مكتوب خطأً، إضافة `استورد` الناقص.
- أوامر: **ضاد: تشغيل الملف الحالي** (`Ctrl+F5`)، **تشغيل الاختبارات**، **شرح كود خطأ**.

## المتطلبات

ثبّت الأداتين من جذر المستودع:

```bash
cargo install --path crates/dhad-cli    # الأمر dhad
cargo install --path crates/dhad-lsp    # خادم اللغة dhad-lsp
```

## الإعدادات

| الإعداد | الافتراضي | الوصف |
|---|---|---|
| `dhad.serverPath` | `dhad-lsp` | مسار خادم اللغة |
| `dhad.cliPath` | `dhad` | مسار الأمر dhad |
| `dhad.easternDigits` | `false` | عرض الأرقام العربية الشرقية في المخرجات |
