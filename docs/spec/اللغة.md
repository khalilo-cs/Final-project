# مرجع لغة ضاد

هذا المرجع يصف اللغة كما ينفّذها المفسر المرجعي (`crates/dhad-syntax` و`crates/dhad-interp`).
كل مثال هنا صحيح ويمكن تشغيله في الساحة أو بالأمر `ضاد شغّل`.

## ١. البنية اللغوية

### الملفات والترميز
- امتداد الملف `.ضاد` (أو `.dhad`)، والترميز UTF-8.
- يُطبَّع النص كاملًا بصيغة **NFC** قبل التحليل، فالمحرف المركّب والمفكك سواء.
- علامات الاتجاه غير المرئية (U+200E و U+200F) وعلامة BOM تُتجاهل.

### الجمل والأسطر
- كل جملة في سطر. يمكن الفصل بين جملتين في سطر واحد بالفاصلة المنقوطة `؛` أو `;`.
- داخل الأقواس `( )` و`[ ]` تُتجاهل نهايات الأسطر، فيمكن تقسيم الاستدعاءات والقوائم الطويلة.

### التعليقات
```dhad
# تعليق حتى نهاية السطر
## تعليق توثيقي: يظهر في تلميحات المحرر فوق الدالة أو المتغير التالي
```

### المعرّفات (الأسماء)
- تبدأ بحرف (عربي أو لاتيني) أو `_`، وتليها حروف أو أرقام أو `_`.
- يجوز أن ينتهي الاسم بعلامة استفهام `؟` (اصطلاح للدوال التي تُرجع صحيح/خطأ): `أولي؟`.
- **التشكيل والكشيدة تُتجاهل**: `عَدَد` و`عــدد` و`عدد` اسم واحد (مع التحذير ضاد-3003).
- **الهمزات لا تُوحَّد**: `اسم` و`إسم` اسمان مختلفان (مع التحذير ضاد-3002 إن اجتمعا).
- **خلط الأحرف العربية واللاتينية في اسم واحد ممنوع** (ضاد-0004)، حماية من المحارف المتشابهة بصريًا.

### الكلمات المحجوزة

| الكلمة | الصيغ المقبولة | المعنى |
|---|---|---|
| `دع` | | تعريف متغير |
| `ثابت` | | تعريف ثابت |
| `إذا` | `اذا` | شرط |
| `وإلا` | `والا` | الفرع البديل |
| `طالما` | | حلقة شرطية |
| `لكل` … `في` | | حلقة تكرار / فحص الانتماء |
| `دالة` | `دالّة` | تعريف دالة |
| `أرجع` | `ارجع` | إرجاع قيمة |
| `توقف` / `استمر` | | التحكم في الحلقات |
| `صحيح` / `خطأ` | `خطا` | القيم المنطقية |
| `و` / `أو` / `ليس` | `او` | العمليات المنطقية |
| `عدم` | | غياب القيمة |
| `استورد` | | استيراد وحدة |
| `اختبر` | | كتلة اختبار |

### الأعداد
- **الأرقام العربية الشرقية (٠-٩) والغربية (0-9) والفارسية (۰-۹) مقبولة كلها**، وتُوحَّد داخليًا.
- الفاصلة العشرية `.` أو الفاصلة العشرية العربية `٫`: `٣٫١٤` و`3.14` سواء.
- يجوز `_` للفصل بين الخانات: `١_٠٠٠_٠٠٠`.
- المخرجات بالأرقام الغربية افتراضيًا، وبالشرقية مع الخيار `--أرقام-شرقية` أو زر الساحة.

### النصوص
```dhad
دع أ = "نص بين علامتي تنصيص"
دع ب = «نص بعلامات التنصيص العربية»
دع س = ٣
اطبع("س = ${س}، وضعفها ${س * ٢}")   # دمج تعبير داخل النص
اطبع("سطر\nسطر آخر")                 # \n أو \س لسطر جديد، \t أو \ت لمسافة جدولة
```

## ٢. الأنواع

| النوع | أمثلة | ملاحظات |
|---|---|---|
| `عدد_صحيح` | `٤٢`، `-٧` | ٦٤-بت؛ عند الفيضان يتحول الناتج إلى عدد عشري |
| `عدد_عشري` | `٣٫١٤`، `٢.٥` | ٦٤-بت |
| `نص` | `"ضاد"` | الفهرسة والطول بالمحارف لا بالبايتات |
| `منطقي` | `صحيح`، `خطأ` | |
| `عدم` | `عدم` | |
| `قائمة` | `[١، "أ"، صحيح]` | مرتبة، قابلة للتعديل، الفهرس يبدأ من ٠ |
| `قاموس` | `{"اسم": "ليلى"، "عمر": ١٧}` | يحفظ ترتيب الإدخال |
| `مدى` | `١..١٠` | نصف مفتوح: ١ حتى ٩ |
| `دالة` | `اطبع`، أو دالة معرَّفة | الدوال قيم: تُمرَّر وتُرجَع |

الدالة `نوع(قيمة)` تُرجع اسم النوع نصًا.

## ٣. العمليات

بالترتيب من الأدنى أولوية إلى الأعلى:

| الأولوية | العمليات | ملاحظات |
|---|---|---|
| ١ | `أو` | قصيرة الدائرة؛ الطرفان منطقيان |
| ٢ | `و` | قصيرة الدائرة |
| ٣ | `==` `!=` `≠` `في` | `في` تفحص الانتماء لقائمة أو نص أو قاموس أو مدى |
| ٤ | `<` `>` `<=` `>=` `≤` `≥` | بين عددين أو بين نصين |
| ٥ | `..` | المدى |
| ٦ | `+` `-` | `+` بين عددين أو نصين أو قائمتين فقط |
| ٧ | `*` `/` `//` `%` `×` `÷` `٪` | `/` تُعطي عددًا عشريًا دائمًا؛ `//` قسمة صحيحة للأسفل؛ `%` باقٍ غير سالب |
| ٨ | `ليس` `-` (أحادية) | |
| ٩ | الاستدعاء `ف()`، الفهرسة `ق[٠]`، العضو `و.ع` | |

**قرارات مقصودة لتقليل التباس المبتدئين:**
- الشروط تقبل `صحيح` و`خطأ` فقط؛ `إذا ١ {…}` خطأ (ضاد-1010). اكتب `إذا س != ٠ {…}`.
- `"العمر: " + ٢٥` خطأ (ضاد-1003). اكتب `"العمر: " + نص(٢٥)` أو `"العمر: ${٢٥}"`.
- `نص * عدد` يكرّر النص: `"ها" * ٣` ← `هاهاها`.

## ٤. الجمل

```dhad
دع العمر = ١٦                 # متغير
ثابت الحد = ١٠٠               # ثابت (ضاد-1002 عند محاولة تغييره)
دع س: عدد = ٥                 # تلميح نوع اختياري (للتوثيق حاليًا)
دع ق = [١، ٢]
دع ط = {"العمر": ١٧}
العمر = العمر + ١             # إسناد
ق[٠] = ٩                      # إسناد إلى عنصر قائمة
ط.العمر = ١٨                  # إسناد إلى مفتاح قاموس

إذا العمر >= ١٨ {
    اطبع("بالغ")
} وإلا إذا العمر >= ١٣ {
    اطبع("مراهق")
} وإلا {
    اطبع("طفل")
}

طالما العمر < ٢٠ {
    العمر = العمر + ١
    إذا العمر == ١٨ { استمر }
    إذا العمر == ١٩ { توقف }
}

لكل ع في ١..٤ { اطبع(ع) }            # مدى
لكل ع في [١٠، ٢٠] { اطبع(ع) }        # قائمة
لكل حرف في "ضاد" { اطبع(حرف) }      # نص
لكل م في {"أ": ١} { اطبع(م) }       # مفاتيح قاموس
```

## ٥. الدوال

```dhad
## يحسب مضروب العدد ن
دالة مضروب(ن) {
    إذا ن <= ١ { أرجع ١ }
    أرجع ن * مضروب(ن - ١)
}

دالة صانع_عداد() {          # الدوال إغلاقات تلتقط نطاقها
    دع ع = ٠
    دالة زد() {
        ع = ع + ١
        أرجع ع
    }
    أرجع زد
}
دع عداد = صانع_عداد()
عداد()
اطبع(عداد())                # 2
```

- دالة بلا `أرجع` تُرجع `عدم`.
- عدد المعاملات يجب أن يطابق التعريف (ضاد-1004).
- عمق الاستدعاء الذاتي محدود بـ ١٠٠٠ (ضاد-2004).
- داخل جسم دالة يجوز استخدام أسماء عامة تُعرَّف لاحقًا (الجسم لا يُنفَّذ إلا عند الاستدعاء)؛ في المستوى الأعلى يجب أن يسبق التعريفُ الاستخدام.

## ٦. الاختبارات المدمجة

```dhad
دالة جمع(أ، ب) { أرجع أ + ب }

اختبر "الجمع تبادلي" {
    لكل س في ٠..٥ {
        تأكد(جمع(س، ١) == جمع(١، س)، "فشل عند ${س}")
    }
}
```

تُشغَّل كتل `اختبر` بالأمر `ضاد اختبر الملف.ضاد` (وتُتجاهل عند `ضاد شغّل`).

## ٧. المكتبة القياسية

### دوال متاحة دائمًا

| الدالة | الوصف |
|---|---|
| `اطبع(قيم...)` | طباعة القيم مفصولة بمسافة |
| `نص(قيمة)` | تحويل إلى نص |
| `عدد(نص)` | تحويل نص إلى عدد (يقبل الأرقام العربية والغربية) |
| `طول(قيمة)` | طول نص أو قائمة أو قاموس أو مدى |
| `نوع(قيمة)` | اسم النوع |
| `مدى(إلى)` / `مدى(من، إلى)` | مدى أعداد |
| `أضف(قائمة، عنصر)` | إضافة إلى نهاية القائمة |
| `احذف(قائمة، فهرس)` / `احذف(قاموس، مفتاح)` | حذف عنصر وإرجاعه |
| `اقرأ(رسالة؟)` | قراءة سطر من المستخدم |
| `تأكد(شرط، رسالة؟)` | إيقاف بخطأ ضاد-2006 إن كان الشرط خطأ |
| `أكبر(...)` / `أصغر(...)` | أكبر/أصغر قيمة (قيم منفصلة أو قائمة) |
| `مطلق(عدد)`، `تقريب(عدد، خانات؟)`، `جذر(عدد)` | دوال عددية |

### الوحدات (`استورد الوحدة`)

| الوحدة | الأعضاء |
|---|---|
| `رياضيات` | `جذر`، `قوة`، `مطلق`، `تقريب`، `سقف`، `أرضية`، `أكبر`، `أصغر`، الثابتان `ط` و`هـ` |
| `نصوص` | `قسّم`، `اربط`، `استبدل`، `يبدأ_بـ`، `ينتهي_بـ`، `يحتوي`، `احذف_التشكيل`، `طبّع`، `اقلب`، `قصّ` |
| `قوائم` | `رتّب`، `اعكس`، `اجمع`، `أضف`، `احذف`، `يحتوي` |
| `وقت` | `الآن`، `انتظر` |
| `عشوائي` | `عدد_عشوائي`، `اختر` |

## ٨. الأخطاء

كل خطأ يحمل كودًا `ضاد-XXXX` وموضعًا ومساعدة، وله صفحة في [docs/errors](../errors/README.md):
٠٠٠١–٠٩٩٩ تحليل، ١٠٠٠–١٩٩٩ دلالة وأنواع، ٢٠٠٠–٢٩٩٩ وقت تشغيل، ٣٠٠٠–٣٩٩٩ تحذيرات، ٤٠٠٠–٤٩٩٩ قيود مولّد WebAssembly.

## ٩. المجموعة الفرعية المترجمة إلى WebAssembly

يترجم `ضاد ترجم` (وزر «⚡ ترجم وشغّل») البرامج التي تقتصر على: الأعداد الصحيحة والقيم المنطقية، المتغيرات
والثوابت، العمليات الحسابية (عدا `/` العشرية) والمنطقية والمقارنات، `إذا`/`طالما`/`لكل ... في مدى`، `توقف`/`استمر`،
الدوال في المستوى الأعلى (بما فيها الاستدعاء الذاتي والمتبادل)، `مطلق`/`أكبر`/`أصغر`، و`اطبع` مع دمج النصوص.
المخرجات مطابقة للمفسر حرفيًا (يتحقق منها `benchmarks/run.mjs --check`)، وما سوى ذلك يُرفض بالخطأ ضاد-4001.
