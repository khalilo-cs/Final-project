# ADR-0003: Rust لغةً للتنفيذ

**الحالة:** مقبول

## السياق
نحتاج: أداءً معقولًا للمفسر، تشغيلًا في المتصفح بلا خادم، خادم LSP، ومنظومة أدوات ناضجة لـ WebAssembly وLSP.

## القرار
النواة والأدوات بلغة Rust. المفسر نفسه يُترجم إلى `wasm32-unknown-unknown` ويعمل في الساحة، والمولّد يستخدم
`wasm-encoder`، وخادم اللغة `lsp-server` و`lsp-types`. الأدوات الطرفية (الساحة، VS Code) بـ JavaScript،
وشارح الأخطاء والتقييم بـ Python.

## البدائل المرفوضة
- **Python:** أبطأ، ولا يعمل في المتصفح إلا بـ Pyodide (عدة ميغابايتات).
- **TypeScript وحدها:** تكفي للمتصفح لكن الأداء والأنواع أضعف لمترجم.

## العواقب
+ ملف ثنائي واحد لكل أداة، ووحدة متصفح ~٧٠٠ كيلوبايت تجمع المفسر والمحلل والمولّد والمنسّق.
− منحنى تعلم أعلى للمساهمين.
