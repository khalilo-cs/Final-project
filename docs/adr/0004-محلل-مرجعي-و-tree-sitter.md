# ADR-0004: محلل مرجعي يدوي + قواعد Tree-sitter للمحررات

**الحالة:** مقبول — يعدّل خطة الوثيقة الأصلية (Tree-sitter محللًا وحيدًا)

## السياق
خطة الوثيقة: Tree-sitter محللًا لكل شيء. أثناء التنفيذ ظهر أن:
١. رسائل الخطأ المرقمة والموجهة للمبتدئ (`كان المتوقع «=» بعد اسم المتغير`) أسهل بكثير في محلل يدوي.
٢. سياسة Unicode (حذف التشكيل، رفض الخلط) تحتاج تحكمًا كاملًا في المحلل اللغوي.
٣. ربط Tree-sitter بالمتصفح يحتاج emscripten، ما يعقّد البناء.

## القرار
- **المحلل المرجعي** (`dhad-syntax`، تنازلي عودي + Pratt) مصدر الدلالات ورسائل الخطأ لكل الأدوات.
- **قواعد Tree-sitter** (`grammar/`) للمحررات التي تعتمد عليه (Neovim، Helix، Zed...) وللتلوين.
- **ضمان التطابق:** `grammar/check-programs.sh` يتحقق في CI أن Tree-sitter يقبل كل برنامج صحيح ويرفض كل
  برنامج خاطئ نحويًا في المستودع (٣٦/٣٦ حاليًا)، و١٠ اختبارات شجرة تثبّت البنية.

## العواقب
+ رسائل خطأ أفضل للمبتدئ. + تحكم كامل في Unicode. − قواعد في مكانين، يحرسهما اختبار التطابق.
− خادم اللغة يعيد التحليل كاملًا عند كل تعديل (سريع بما يكفي لملفات تعليمية؛ التحليل التزايدي عمل مستقبلي).
