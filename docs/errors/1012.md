# ضاد-1012: لا يمكن الإسناد إلى هذا الهدف

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

الطرف الأيسر من = يجب أن يكون مكانًا قابلًا للكتابة.

## مثال يسبب الخطأ

```dhad
٥ = ٣
```

رسالة المترجم:

```text
خطأ[ضاد-1012]: لا يمكن الإسناد إلى هذا التعبير
  ← الملف: مثال.ضاد — السطر 1، العمود 1
  │
1 │ ٥ = ٣
  │ ^
  = مساعدة: الإسناد يكون إلى متغير أو عنصر قائمة أو مفتاح قاموس.
  = لمزيد من التفاصيل: ضاد شرح 1012
```

## كيف أصلحه؟

الإسناد يكون إلى متغير أو عنصر قائمة أو مفتاح قاموس.

```dhad
دع س = ٣
س = ٥
اطبع(س)
```

المخرجات بعد الإصلاح:

```text
5
```
