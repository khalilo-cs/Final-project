# ضاد-2007: نوع غير متوقع

> الفئة: **أخطاء وقت التشغيل** — تظهر أثناء تنفيذ البرنامج بقيم معيّنة.

## ماذا يعني؟

مرّرت قيمة من نوع لا تقبله هذه الدالة أو العملية.

## مثال يسبب الخطأ

```dhad
اطبع(طول(١٢٣))
```

رسالة المترجم:

```text
خطأ[ضاد-2007]: الدالة «طول» تتوقع نصًا أو قائمة أو قاموسًا لكنها تلقّت قيمة من نوع عدد_صحيح
  ← الملف: مثال.ضاد — السطر 1، العمود 6
  │
1 │ اطبع(طول(١٢٣))
  │      ^^^^^^^^
  = مساعدة: راجع نوع القيمة الممررة؛ استخدم نوع(القيمة).
  = لمزيد من التفاصيل: ضاد شرح 2007
```

## كيف أصلحه؟

راجع نوع القيمة الممررة؛ استخدم نوع(القيمة).

```dhad
اطبع(طول("١٢٣"))
```

المخرجات بعد الإصلاح:

```text
3
```
