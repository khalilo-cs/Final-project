# ضاد-1007: «توقف» أو «استمر» خارج حلقة

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

جملتا التحكم في الحلقات لا معنى لهما خارج حلقة.

## مثال يسبب الخطأ

```dhad
توقف
```

رسالة المترجم:

```text
خطأ[ضاد-1007]: «توقف» خارج حلقة
  ← الملف: مثال.ضاد — السطر 1، العمود 1
  │
1 │ توقف
  │ ^^^^
  = مساعدة: تُستخدم هاتان الكلمتان داخل «طالما» أو «لكل» فقط.
  = لمزيد من التفاصيل: ضاد شرح 1007
```

## كيف أصلحه؟

تُستخدم هاتان الكلمتان داخل «طالما» أو «لكل» فقط.

```dhad
لكل ع في ١..١٠ {
    إذا ع == ٣ { توقف }
    اطبع(ع)
}
```

المخرجات بعد الإصلاح:

```text
1
2
```
