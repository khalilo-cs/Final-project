# ضاد-2002: فهرس خارج حدود القائمة

> الفئة: **أخطاء وقت التشغيل** — تظهر أثناء تنفيذ البرنامج بقيم معيّنة.

## ماذا يعني؟

حاولت الوصول إلى عنصر بفهرس أكبر من أو يساوي طول القائمة أو أصغر من صفر.

## مثال يسبب الخطأ

```dhad
دع ق = [١، ٢]
اطبع(ق[٥])
```

رسالة المترجم:

```text
خطأ[ضاد-2002]: الفهرس 5 خارج الحدود (الطول 2)
  ← الملف: مثال.ضاد — السطر 2، العمود 8
  │
2 │ اطبع(ق[٥])
  │        ^
  = مساعدة: الفهارس تبدأ من ٠ وتنتهي عند طول(القائمة) - ١.
  = لمزيد من التفاصيل: ضاد شرح 2002
```

## كيف أصلحه؟

الفهارس تبدأ من ٠ وتنتهي عند طول(القائمة) - ١.

```dhad
دع ق = [١، ٢]
اطبع(ق[طول(ق) - ١])
```

المخرجات بعد الإصلاح:

```text
2
```
