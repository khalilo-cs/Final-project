# ضاد-2008: تعذّر تحويل النص إلى عدد

> الفئة: **أخطاء وقت التشغيل** — تظهر أثناء تنفيذ البرنامج بقيم معيّنة.

## ماذا يعني؟

دالة عدد(...) تلقّت نصًا لا يمثل عددًا صالحًا.

## مثال يسبب الخطأ

```dhad
اطبع(عدد("abc"))
```

رسالة المترجم:

```text
خطأ[ضاد-2008]: تعذّر تحويل النص «abc» إلى عدد
  ← الملف: مثال.ضاد — السطر 1، العمود 6
  │
1 │ اطبع(عدد("abc"))
  │      ^^^^^^^^^^
  = مساعدة: تأكد من أن النص يحتوي أرقامًا فقط (عربية أو غربية).
  = لمزيد من التفاصيل: ضاد شرح 2008
```

## كيف أصلحه؟

تأكد من أن النص يحتوي أرقامًا فقط (عربية أو غربية).

```dhad
اطبع(عدد("٤٢") + ١)
```

المخرجات بعد الإصلاح:

```text
43
```
