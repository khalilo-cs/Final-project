# ضاد-1006: «أرجع» خارج دالة

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

جملة «أرجع» لا معنى لها إلا داخل جسم دالة.

## مثال يسبب الخطأ

```dhad
أرجع ١
```

```text

  │ ^^^^^^
  = مساعدة: انقل الجملة داخل دالة أو احذفها.
  = لمزيد من التفاصيل: ضاد شرح 1006
```
