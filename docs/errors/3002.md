# ضاد-3002: معرّفان متشابهان

> الفئة: **تحذيرات المدقق** — لا توقف البرنامج، لكنها تشير غالبًا إلى خطأ أو التباس.

## ماذا يعني؟

تحذير: يوجد معرّفان لا يختلفان إلا بالهمزة أو التاء المربوطة/الهاء.

## مثال يسبب الخطأ

```dhad
دع أسماء = ["ليلى"]
دع اسماء = ["سارة"]
اطبع(أسماء، اسماء)
```

رسالة المترجم:

```text
تحذير[ضاد-3002]: «اسماء» و«أسماء» لا يختلفان إلا بالهمزة أو التاء المربوطة أو الياء
  ← الملف: مثال.ضاد — السطر 2، العمود 4
  │
2 │ دع اسماء = ["سارة"]
  │    ^^^^^
  = مساعدة: وحّد التهجئة لتجنب الالتباس.
  = لمزيد من التفاصيل: ضاد شرح 3002
```

## كيف أصلحه؟

وحّد التهجئة لتجنب الالتباس.

```dhad
دع أسماء = ["ليلى"، "سارة"]
اطبع(أسماء)
```

المخرجات بعد الإصلاح:

```text
["ليلى"، "سارة"]
```
