# ضاد-1010: الشرط ليس قيمة منطقية

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

شروط «إذا» و«طالما» تقبل فقط صحيح أو خطأ. لا تُعامل الأعداد أو النصوص كقيم منطقية ضمنيًا، لتجنب التباس المبتدئين.

## مثال يسبب الخطأ

```dhad
إذا ١ { اطبع("؟") }
```

رسالة المترجم:

```text
خطأ[ضاد-1010]: الشرط يجب أن يكون صحيح أو خطأ، لكنه قيمة من نوع عدد_صحيح
  ← الملف: مثال.ضاد — السطر 1، العمود 5
  │
1 │ إذا ١ { اطبع("؟") }
  │     ^
  = مساعدة: استخدم مقارنة صريحة مثل: س != ٠ أو طول(القائمة) > ٠
  = لمزيد من التفاصيل: ضاد شرح 1010
```

## كيف أصلحه؟

استخدم مقارنة صريحة مثل: س != ٠ أو طول(القائمة) > ٠

```dhad
دع س = ١
إذا س != ٠ { اطبع("غير صفر") }
```

المخرجات بعد الإصلاح:

```text
غير صفر
```
