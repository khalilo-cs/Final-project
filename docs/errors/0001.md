# ضاد-0001: رمز غير متوقع

> الفئة: **أخطاء التحليل اللغوي والنحوي** — تُكتشف قبل التشغيل: صياغة البرنامج نفسها غير صحيحة.

## ماذا يعني؟

وجد المحلل رمزًا لا تسمح به قواعد اللغة في هذا الموضع. غالبًا ما يكون السبب نسيان قوس أو فاصلة أو كتابة كلمة مفتاحية في مكان خاطئ.

## مثال يسبب الخطأ

```dhad
دع س = ١ ٢
```

رسالة المترجم:

```text
خطأ[ضاد-0001]: رمز غير متوقع: العدد 2، كان المتوقع نهاية السطر
  ← الملف: مثال.ضاد — السطر 1، العمود 10
  │
1 │ دع س = ١ ٢
  │          ^
  = مساعدة: راجع الرمز المتوقع في هذا الموضع.
  = لمزيد من التفاصيل: ضاد شرح 0001
```

## كيف أصلحه؟

راجع الرمز المتوقع في هذا الموضع.

```dhad
دع س = ١٢
```
