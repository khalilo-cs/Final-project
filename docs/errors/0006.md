# ضاد-0006: عدد غير صالح

> الفئة: **أخطاء التحليل اللغوي والنحوي** — تُكتشف قبل التشغيل: صياغة البرنامج نفسها غير صحيحة.

## ماذا يعني؟

تعذّر قراءة العدد. يُقبل في العدد الواحد أرقام عربية شرقية أو غربية مع فاصلة عشرية واحدة.

## مثال يسبب الخطأ

```dhad
دع س = ١٢أ
```

رسالة المترجم:

```text
خطأ[ضاد-0006]: عدد غير صالح: «12أ»
  ← الملف: مثال.ضاد — السطر 1، العمود 8
  │
1 │ دع س = ١٢أ
  │        ^^^
  = مساعدة: تأكد من صيغة العدد؛ الفاصلة العشرية الصحيحة هي . أو ٫
  = لمزيد من التفاصيل: ضاد شرح 0006
```

## كيف أصلحه؟

تأكد من صيغة العدد؛ الفاصلة العشرية الصحيحة هي . أو ٫

```dhad
دع س = ١٢
اطبع(س)
```

المخرجات بعد الإصلاح:

```text
12
```
