# ضاد-1001: متغير غير معرَّف

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

استُخدم اسم لم يُعرَّف في هذا النطاق أو في أي نطاق أعلى. تحقق من التهجئة (الهمزات والتاء المربوطة) ومن أن التعريف يسبق الاستخدام.

## مثال يسبب الخطأ

```dhad
دع المجموع = ١٠
اطبع(المجموغ)
```

رسالة المترجم:

```text
خطأ[ضاد-1001]: المتغير «المجموغ» غير معرَّف
  ← الملف: مثال.ضاد — السطر 2، العمود 6
  │
2 │ اطبع(المجموغ)
  │      ^^^^^^^
  = مساعدة: هل تقصد «المجموع»؟ وإلا عرّفه أولًا بـ: دع المجموغ = ...
  = لمزيد من التفاصيل: ضاد شرح 1001
```

## كيف أصلحه؟

عرّف المتغير بـ «دع» قبل استخدامه، أو تحقق من التهجئة.

```dhad
دع المجموع = ١٠
اطبع(المجموع)
```

المخرجات بعد الإصلاح:

```text
10
```
