# ضاد-2001: قسمة على صفر

> الفئة: **أخطاء وقت التشغيل** — تظهر أثناء تنفيذ البرنامج بقيم معيّنة.

## ماذا يعني؟

القسمة أو باقي القسمة على صفر غير معرَّفة رياضيًا.

## مثال يسبب الخطأ

```dhad
اطبع(١٠ / ٠)
```

رسالة المترجم:

```text
خطأ[ضاد-2001]: قسمة على صفر
  ← الملف: مثال.ضاد — السطر 1، العمود 6
  │
1 │ اطبع(١٠ / ٠)
  │      ^^^^^^
  = مساعدة: تحقق من المقسوم عليه قبل القسمة.
  = لمزيد من التفاصيل: ضاد شرح 2001
```

## كيف أصلحه؟

تحقق من المقسوم عليه قبل القسمة.

```dhad
دع ب = ٠
إذا ب != ٠ { اطبع(١٠ / ب) } وإلا { اطبع("لا يمكن القسمة على صفر") }
```

المخرجات بعد الإصلاح:

```text

```
