# ضاد-4002: نوع غير متوافق في مولّد WebAssembly

> الفئة: **قيود مولّد WebAssembly** — تظهر فقط عند الترجمة بـ «ضاد ترجم»؛ المفسر يشغّل البرنامج عادةً.

## ماذا يعني؟

المولّد يستنتج نوعًا ثابتًا لكل متغير ودالة. تغيير نوع متغير (عدد ثم منطقي مثلًا) يمنع الترجمة.

## مثال يسبب الخطأ

```dhad
دع س = ١
س = صحيح
اطبع(س)
```

رسالة المترجم:

```text
خطأ[ضاد-4002]: قيمة «س» يجب أن تكون عدد_صحيح لكنها منطقي
  ← الملف: مثال.ضاد — السطر 2، العمود 5
  │
2 │ س = صحيح
  │     ^^^^
  = مساعدة: اجعل المتغير يحتفظ بنوع واحد طوال البرنامج.
  = لمزيد من التفاصيل: ضاد شرح 4002
```

## كيف أصلحه؟

اجعل المتغير يحتفظ بنوع واحد طوال البرنامج.

```dhad
دع س = ١
س = ٢
اطبع(س)
```

المخرجات بعد الإصلاح:

```text

```
