# ضاد-1011: العملية غير معرَّفة لهذين النوعين

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

طُبِّقت عملية حسابية أو منطقية على أنواع لا تدعمها.

## مثال يسبب الخطأ

```dhad
اطبع(صحيح + ١)
```

رسالة المترجم:

```text
خطأ[ضاد-1011]: العملية «+» غير معرَّفة بين منطقي وعدد_صحيح
  ← الملف: مثال.ضاد — السطر 1، العمود 6
  │
1 │ اطبع(صحيح + ١)
  │      ^^^^^^^^
  = مساعدة: راجع أنواع الطرفين؛ استخدم نوع(القيمة) لمعرفة النوع.
  = لمزيد من التفاصيل: ضاد شرح 1011
```

## كيف أصلحه؟

راجع أنواع الطرفين؛ استخدم نوع(القيمة) لمعرفة النوع.

```dhad
اطبع(١ + ١)
```

المخرجات بعد الإصلاح:

```text
2
```
