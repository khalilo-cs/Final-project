# ضاد-0005: كلمة مفتاحية مستخدمة كاسم

> الفئة: **أخطاء التحليل اللغوي والنحوي** — تُكتشف قبل التشغيل: صياغة البرنامج نفسها غير صحيحة.

## ماذا يعني؟

الكلمات مثل دع، إذا، طالما، دالة محجوزة ولا يمكن استخدامها كأسماء متغيرات أو دوال.

## مثال يسبب الخطأ

```dhad
دع طالما = ١
```

رسالة المترجم:

```text
خطأ[ضاد-0005]: «طالما» كلمة محجوزة في اللغة ولا يمكن استخدامها هنا (المتوقع: اسم متغير)
  ← الملف: مثال.ضاد — السطر 1، العمود 4
  │
1 │ دع طالما = ١
  │    ^^^^^
  = مساعدة: اختر اسمًا آخر؛ هذه الكلمة محجوزة للغة.
  = لمزيد من التفاصيل: ضاد شرح 0005
```

## كيف أصلحه؟

اختر اسمًا آخر؛ هذه الكلمة محجوزة للغة.

```dhad
دع مدة = ١
اطبع(مدة)
```

المخرجات بعد الإصلاح:

```text
1
```
