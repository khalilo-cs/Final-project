# ضاد-0002: قوس غير مغلق

> الفئة: **أخطاء التحليل اللغوي والنحوي** — تُكتشف قبل التشغيل: صياغة البرنامج نفسها غير صحيحة.

## ماذا يعني؟

فُتح قوس ( أو [ أو { ولم يُغلق. يشير الخطأ إلى موضع القوس المفتوح.

## مثال يسبب الخطأ

```dhad
اطبع((١ + ٢)
```

رسالة المترجم:

```text
خطأ[ضاد-0002]: القوس «(» لم يُغلق
  ← الملف: مثال.ضاد — السطر 1، العمود 5
  │
1 │ اطبع((١ + ٢)
  │     ^
  = مساعدة: أغلق القوس المفتوح قبل نهاية الملف.
  = لمزيد من التفاصيل: ضاد شرح 0002
```

## كيف أصلحه؟

أغلق القوس المفتوح قبل نهاية الملف.

```dhad
اطبع((١ + ٢))
```

المخرجات بعد الإصلاح:

```text
3
```
