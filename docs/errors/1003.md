# ضاد-1003: لا يمكن جمع نص مع عدد

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

العملية + تعمل بين عددين (جمع حسابي) أو بين نصين (ضم). الجمع بين نص وعدد غامض، لذلك ترفضه اللغة وتطلب تحويلًا صريحًا.

## مثال يسبب الخطأ

```dhad
اطبع("العمر: " + ٢٥)
```

رسالة المترجم:

```text
خطأ[ضاد-1003]: لا يمكن جمع نص مع عدد
  ← الملف: مثال.ضاد — السطر 1، العمود 6
  │
1 │ اطبع("العمر: " + ٢٥)
  │      ^^^^^^^^^^^^^^
  = مساعدة: حوّل العدد إلى نص بـ نص(العدد)، أو استخدم دمج النصوص "${...}".
  = لمزيد من التفاصيل: ضاد شرح 1003
```

## كيف أصلحه؟

حوّل العدد إلى نص بـ نص(العدد)، أو استخدم دمج النصوص "${...}".

```dhad
اطبع("العمر: " + نص(٢٥))
اطبع("العمر: ${٢٥}")
```

المخرجات بعد الإصلاح:

```text
العمر: 25
العمر: 25
```
