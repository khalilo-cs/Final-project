# ضاد-2004: تجاوز عمق الاستدعاء

> الفئة: **أخطاء وقت التشغيل** — تظهر أثناء تنفيذ البرنامج بقيم معيّنة.

## ماذا يعني؟

استدعت الدالة نفسها مرات كثيرة جدًا دون الوصول إلى حالة أساس.

## مثال يسبب الخطأ

```dhad
دالة بلا_نهاية(ن) { أرجع بلا_نهاية(ن + ١) }
بلا_نهاية(٠)
```

رسالة المترجم:

```text
خطأ[ضاد-2004]: تجاوز عمق الاستدعاء (1000) في الدالة «بلا_نهاية»
  ← الملف: مثال.ضاد — السطر 1، العمود 26
  │
1 │ دالة بلا_نهاية(ن) { أرجع بلا_نهاية(ن + ١) }
  │                          ^^^^^^^^^^^^^^^^
  = مساعدة: تحقق من شرط التوقف في الدالة ذاتية الاستدعاء.
  = لمزيد من التفاصيل: ضاد شرح 2004
```

## كيف أصلحه؟

تحقق من شرط التوقف في الدالة ذاتية الاستدعاء.

```dhad
دالة عد_تنازلي(ن) {
    إذا ن == ٠ { أرجع ٠ }
    أرجع عد_تنازلي(ن - ١)
}
اطبع(عد_تنازلي(١٠))
```

المخرجات بعد الإصلاح:

```text
0
```
