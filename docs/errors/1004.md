# ضاد-1004: عدد المعاملات لا يطابق تعريف الدالة

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

استُدعيت دالة بعدد معاملات مختلف عما عُرِّفت به.

## مثال يسبب الخطأ

```dhad
دالة ف(أ) { أرجع أ }
ف(١، ٢)
```

رسالة المترجم:

```text
خطأ[ضاد-1004]: الدالة «ف» تتوقع 1 من المعاملات لكنها تلقّت 2
  ← الملف: مثال.ضاد — السطر 2، العمود 1
  │
2 │ ف(١، ٢)
  │ ^^^^^^^
  = مساعدة: راجع توقيع الدالة وعدد معاملاتها.
  = لمزيد من التفاصيل: ضاد شرح 1004
```

## كيف أصلحه؟

راجع توقيع الدالة وعدد معاملاتها.

```dhad
دالة ف(أ) { أرجع أ }
اطبع(ف(١))
```

المخرجات بعد الإصلاح:

```text
1
```
