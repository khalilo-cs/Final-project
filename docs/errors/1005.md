# ضاد-1005: استدعاء قيمة ليست دالة

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

استُخدمت أقواس الاستدعاء ( ) بعد قيمة ليست دالة.

## مثال يسبب الخطأ

```dhad
دع س = ٥
س()
```

رسالة المترجم:

```text
خطأ[ضاد-1005]: لا يمكن استدعاء قيمة من نوع عدد_صحيح
  ← الملف: مثال.ضاد — السطر 2، العمود 1
  │
2 │ س()
  │ ^^^
  = مساعدة: تحقق من أن الاسم يشير إلى دالة لا إلى متغير عادي.
  = لمزيد من التفاصيل: ضاد شرح 1005
```

## كيف أصلحه؟

تحقق من أن الاسم يشير إلى دالة لا إلى متغير عادي.

```dhad
دالة س() { أرجع ٥ }
اطبع(س())
```

```text

```
