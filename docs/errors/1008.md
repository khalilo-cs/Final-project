# ضاد-1008: مقارنة بين نوعين غير متوافقين

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

عمليات < و > و <= و >= تعمل بين عددين أو بين نصين فقط.

## مثال يسبب الخطأ

```dhad
اطبع(١ < "٢")
```

رسالة المترجم:

```text
خطأ[ضاد-1008]: لا يمكن المقارنة بين عدد_صحيح ونص
  ← الملف: مثال.ضاد — السطر 1، العمود 6
  │
1 │ اطبع(١ < "٢")
  │      ^^^^^^^
  = مساعدة: حوّل أحد الطرفين إلى نوع الآخر قبل المقارنة.
  = لمزيد من التفاصيل: ضاد شرح 1008
```

## كيف أصلحه؟

حوّل أحد الطرفين إلى نوع الآخر قبل المقارنة.

```dhad
اطبع(١ < عدد("٢"))
```
