# ضاد-1002: إعادة تعيين ثابت

> الفئة: **أخطاء دلالية وأنواع** — الصياغة سليمة لكن المعنى غير صالح: اسم غير معرَّف، نوع غير مناسب…

## ماذا يعني؟

القيم المعرَّفة بـ «ثابت» لا يمكن تعديلها بعد تعريفها.

## مثال يسبب الخطأ

```dhad
ثابت ط = ٣
ط = ٤
```

رسالة المترجم:

```text
خطأ[ضاد-1002]: «ط» ثابت ولا يمكن تغيير قيمته
  ← الملف: مثال.ضاد — السطر 2، العمود 1
  │
2 │ ط = ٤
  │ ^
  = مساعدة: الثوابت لا تتغير؛ استخدم «دع» إن أردت قيمة قابلة للتغيير.
  = لمزيد من التفاصيل: ضاد شرح 1002
```

## كيف أصلحه؟

الثوابت لا تتغير؛ استخدم «دع» إن أردت قيمة قابلة للتغيير.

```dhad
دع ط = ٣
ط = ٤
اطبع(ط)
```

المخرجات بعد الإصلاح:

```text
4
```
