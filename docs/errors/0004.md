# ضاد-0004: معرّف يخلط محارف من نصوص مختلفة

> الفئة: **أخطاء التحليل اللغوي والنحوي** — تُكتشف قبل التشغيل: صياغة البرنامج نفسها غير صحيحة.

## ماذا يعني؟

خلط أحرف عربية ولاتينية متشابهة بصريًا في اسم واحد يسبب أخطاء يصعب اكتشافها (UTS #39)، لذلك ترفضه اللغة.

## مثال يسبب الخطأ

```dhad
دع عددx = ١
```

رسالة المترجم:

```text
خطأ[ضاد-0004]: المعرّف «عددx» يخلط أحرفًا عربية ولاتينية
  ← الملف: مثال.ضاد — السطر 1، العمود 4
  │
1 │ دع عددx = ١
  │    ^^^^
  = مساعدة: استخدم محارف عربية فقط أو لاتينية فقط في المعرّف الواحد.
  = لمزيد من التفاصيل: ضاد شرح 0004
```

## كيف أصلحه؟

استخدم محارف عربية فقط أو لاتينية فقط في المعرّف الواحد.

```dhad
دع عدد١ = ١
اطبع(عدد١)
```

المخرجات بعد الإصلاح:

```text
1
```
