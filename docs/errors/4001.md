# ضاد-4001: بنية غير مدعومة في مولّد WebAssembly

> الفئة: **قيود مولّد WebAssembly** — تظهر فقط عند الترجمة بـ «ضاد ترجم»؛ المفسر يشغّل البرنامج عادةً.

## ماذا يعني؟

مولّد WebAssembly يترجم حاليًا مجموعة فرعية عددية من اللغة. البرنامج يستخدم بنية خارجها (مثل القوائم أو الأعداد العشرية أو الوحدات).

## مثال يسبب الخطأ

```dhad
دع ق = [١، ٢، ٣]
اطبع(ق)
```

رسالة المترجم:

```text
خطأ[ضاد-4001]: القوائم والقواميس غير مدعوم بعد في مولّد WebAssembly
  ← الملف: مثال.ضاد — السطر 1، العمود 8
  │
1 │ دع ق = [١، ٢، ٣]
  │        ^^^^^^^^^
  = مساعدة: المدعوم: الأعداد الصحيحة والقيم المنطقية، الدوال، الشروط والحلقات على المدى، والطباعة. شغّل البرنامج بالمفسر لبقية اللغة.
  = لمزيد من التفاصيل: ضاد شرح 4001
```

## كيف أصلحه؟

شغّل البرنامج بالمفسر، أو اقتصر على الأعداد الصحيحة والقيم المنطقية والدوال والشروط والحلقات على المدى.

```dhad
دع مجموع = ٠
لكل ع في ١..٤ { مجموع = مجموع + ع }
اطبع(مجموع)
```
