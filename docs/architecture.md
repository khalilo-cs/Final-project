# معمارية منصة ضاد

## نظرة عامة

```
                       ┌──────────────── الطبقة الرابعة: التعلم والتقييم ────────────────┐
                       │ learn/lessons.mjs (١٠ دروس بمصحّح آلي)   benchmarks/   ai-explainer/eval/ │
                       └───────────────────────────────────────────────────────────────────┘
                       ┌──────────────── الطبقة الثالثة: الشرح الذكي ────────────────────┐
                       │ ai-explainer: موجّه مقيَّد بـ docs/errors ← مزود ← حارس ← احتياطي   │
                       └───────────────────────────────────────────────────────────────────┘
┌──────────────────────────────── الطبقة الثانية: أدوات المطور ───────────────────────────────┐
│ dhad-cli (الأمر ضاد)  dhad-lsp (خادم اللغة)  editors/vscode  editors/web (الساحة)  grammar/   │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
┌──────────────────────────────── الطبقة الأولى: النواة اللغوية ──────────────────────────────┐
│ dhad-diagnostics → dhad-syntax → dhad-analysis → dhad-interp │ dhad-wasmgen │ dhad-fmt       │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

## الحزم (crates)

| الحزمة | المسؤولية | تعتمد على |
|---|---|---|
| `dhad-diagnostics` | نوع التشخيص، فهرس الأخطاء الموثّق، العرض النصي وJSON | — |
| `dhad-syntax` | سياسة Unicode، المحلل اللغوي، المحلل النحوي، شجرة البرنامج | diagnostics |
| `dhad-analysis` | جدول الرموز، حل الأسماء، التحذيرات، معلومات الأدوات | syntax |
| `dhad-interp` | المفسر، البيئات والإغلاقات، عدّاد الوقود، المكتبة القياسية | syntax |
| `dhad-wasmgen` | مولّد WebAssembly للمجموعة العددية + طابعة WAT | syntax |
| `dhad-fmt` | المنسّق (يغيّر المسافات فقط) | syntax |
| `dhad-cli` | الأمر `ضاد`: شغّل، افحص، اختبر، ترجم، نسّق، شرح، فهرس، REPL | الكل |
| `dhad-lsp` | خادم LSP عبر stdio | analysis، fmt |
| `dhad-wasm` | واجهة C ABI لتشغيل كل ما سبق في المتصفح | interp، analysis، wasmgen، fmt |

## مسارات التنفيذ الثلاثة

```
 النص ─► NFC ─► المحلل اللغوي ─► المحلل النحوي ─► شجرة البرنامج
                                                     │
            ┌────────────────────────────────────────┼─────────────────────────────┐
            ▼                                        ▼                             ▼
   المفسر الأصلي (dhad شغّل)            المفسر مترجمًا إلى WASM           مولّد WASM (dhad ترجم)
   بناء أصلي للنظام                      (الساحة: زر ▶ تشغيل)           وحدة .wasm صغيرة لكل برنامج
                                                                         (الساحة: زر ⚡ ترجم وشغّل)
```

المساران الأول والثاني هما الشيفرة نفسها مترجمةً لهدفين. المسار الثالث مترجم حقيقي، ومخرجاته
تُقارَن حرفيًا بالمفسر في `benchmarks/run.mjs --check` على كل برامج القياس والحالات الحدية.

## مصدر واحد للحقيقة في كل طبقة

| المعلومة | المصدر | المستهلكون |
|---|---|---|
| قواعد اللغة ودلالاتها | `dhad-syntax` + `dhad-interp` | كل شيء؛ قواعد Tree-sitter تُختبر مقابلها (`grammar/check-programs.sh`) |
| أكواد الأخطاء وشروحها | `CATALOG` في `dhad-diagnostics` | المترجم، `ضاد شرح`، `docs/errors` (مولَّدة)، الشارح الذكي، الساحة |
| الدوال المدمجة والوحدات | `dhad-interp/builtins.rs` | `dhad-analysis/catalog.rs` (اختبار يتحقق من التطابق)، الإكمال في المحررات |
| حل الأسماء والتحذيرات | `dhad-analysis` | `ضاد افحص`، LSP، التشخيص الفوري في الساحة |

## الساحة في المتصفح

```
 main.js (الواجهة)                         worker.js (Web Worker معزول)
 ├─ CodeMirror 6 + طبقة BiDi                ├─ dhad.wasm: run / check / compile / format / explain
 ├─ إكمال تلقائي ولغة ضاد                    └─ تشغيل الوحدات المترجمة من برامج المستخدم
 ├─ تشخيص فوري ← ask("check")
 ├─ تشغيل ← ask("run") ── مهلة ٥ ث: يُنهى العامل ويُستبدل
 ├─ ترجمة ← ask("compile-run")
 └─ الدروس ← gradedSource + judge (learn/lessons.mjs)
```

لا خادم: كل شيء ملف ثابت، والكود المشارك محفوظ في الرابط نفسه (مضغوطًا بـ deflate).

## طبقة BiDi

الاتجاه الأساسي للمحرر RTL دائمًا، و`editors/web/src/bidi.js` يحدد مقاطع تُعزل اتجاهيًا:
المعرّفات اللاتينية والأرقام الغربية (LTR) والنصوص والتعليقات (اتجاه تلقائي من محتواها).
تُطبَّق عبر `EditorView.bidiIsolatedRanges` في CodeMirror، فتتحرك المؤشرات بصريًا بشكل صحيح أيضًا.
