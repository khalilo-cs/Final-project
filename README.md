# منصة برمجة عربية متكاملة — مشروع التخرج

لغة برمجة عربية بمحلل نحوي تزايدي، مفسر، مترجم إلى WebAssembly، خادم LSP، محرر ويب يدعم RTL/BiDi، وشارح أخطاء ذكي بالعربية.

## الوثائق

- [وثيقة المشروع الأساسية](docs/01-وثيقة-المشروع.md) — الملخص التنفيذي، تحليل الفجوة، البنية المعمارية بطبقاتها الأربع، خطة التنفيذ، والمخاطر.
- [التحسينات والإضافات](docs/02-التحسينات-والإضافات.md) — مزايا إضافية لكل طبقة، طبقات جديدة (التعليم، الجودة الهندسية، الأمان، إتاحة الوصول)، هيكلة المستودع المقترحة، وترتيب أولويات MoSCoW.

## الطبقات الأربع

1. **النواة اللغوية** — Tree-sitter grammar + مفسر (Rust) + توليد WASM.
2. **أدوات المطور** — خادم LSP + إضافة VS Code + محرر ويب RTL/BiDi.
3. **الذكاء الاصطناعي** — شارح أخطاء عربي مقيَّد بالتوثيق (RAG) مع حارس جودة.
4. **التقييم التجريبي** — أداء، دقة LSP، فهم الأخطاء، صحة BiDi، قابلية الاستخدام (SUS).
