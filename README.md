# ضاد — منصة برمجة عربية متكاملة

**لغة برمجة عربية، بمفسر ومترجم إلى WebAssembly، وخادم لغة (LSP)، ومحرر ويب بدعم RTL/BiDi أصيل،
وشارح أخطاء ذكي مقيَّد بالتوثيق، وعشرة دروس تفاعلية — مع تقييم تجريبي قابل لإعادة الإنتاج.**

```dhad
استورد رياضيات

## يُرجع صحيح إن كان العدد أوليًا
دالة أولي؟(ع) {
    إذا ع < ٢ { أرجع خطأ }
    لكل ق في ٢..ع {
        إذا ق * ق > ع { توقف }
        إذا ع % ق == ٠ { أرجع خطأ }
    }
    أرجع صحيح
}

لكل ع في ١..٢٠ {
    إذا أولي؟(ع) { اطبع("${ع} عدد أولي") }
}
اطبع("جذر ٢ ≈", رياضيات.تقريب(رياضيات.جذر(٢)، ٤))
```

## ابدأ في دقيقة

```bash
cargo build --release                          # الأدوات
./target/release/dhad شغّل examples/الأعداد_الأولية.ضاد
./target/release/dhad                          # جلسة تفاعلية
```

| الأمر | الوظيفة |
|---|---|
| `ضاد شغّل ملف.ضاد` | تشغيل بالمفسر (`--أرقام-شرقية`، `--وقود N`، `--json`) |
| `ضاد افحص ملف.ضاد` | فحص ثابت: أخطاء وتحذيرات قبل التشغيل |
| `ضاد اختبر ملف.ضاد` | تشغيل كتل `اختبر` المدمجة |
| `ضاد ترجم ملف.ضاد` | ترجمة إلى WebAssembly (`-o`، `--wat`) |
| `ضاد نسّق ملفات.ضاد` | تنسيق بالأسلوب القياسي (`--تحقق`) |
| `ضاد شرح 1003` | شرح كود خطأ |

**الساحة في المتصفح** (بلا تثبيت، بلا خادم):

```bash
cd editors/web && npm ci && npm run build && npm run serve   # http://127.0.0.1:8080
```

**VS Code:** `cd editors/vscode && npm ci && npm run package` ثم ثبّت ملف `.vsix` (يحتاج `cargo install --path crates/dhad-lsp`).

**الشارح الذكي:** `python -m dhad_explainer ملف.ضاد --كل` (انظر [ai-explainer](ai-explainer/README.md)).

| | إضافة VS Code (عميل LSP، تلوين TextMate، مقتطفات، أوامر) | ✅ |

| **٣ — الذكاء الاصطناعي** | شارح بأربعة مستويات، مقيَّد بالتوثيق، بحارس جودة واحتياطي حتمي (Claude / Ollama / بلا شبكة) | ✅ |
| **٤ — التعلم والتقييم** | ١٠ دروس بمصحّح آلي في المتصفح | ✅ |
| | قياس الأداء والاختبار التفاضلي بين ثلاثة مسارات تنفيذ | ✅ |
| | أدوات تقييم الشارح (آلي + بشري مزدوج التعمية + κ) | ✅ |
| | بروتوكول دراسة المستخدمين ومواده وتحليله ([evaluation](evaluation/README.md)) | ✅ جاهز للتنفيذ |

## نتائج القياس

البرنامج نفسه بثلاثة مسارات، بعد التحقق من تطابق المخرجات حرفيًا ([التفاصيل](benchmarks/results/latest.md)):

| البرنامج | المفسر الأصلي | المفسر في WASM | **المترجم إلى WASM** | التسريع |
|---|---:|---:|---:|---:|
| فيبوناتشي ذاتي (٢٥) | 149 ms | 132 ms | **0.59 ms** | ×252 |
| الأعداد الأولية تحت ٢٠٠٠٠ | 167 ms | 212 ms | **1.2 ms** | ×140 |
| ق.م.أ لكل الأزواج حتى ٣٠٠ | 304 ms | 370 ms | **3.2 ms** | ×95 |
| حلقة حسابية (٣٠٠ ألف) | 213 ms | 247 ms | **3.1 ms** | ×69 |
| كولاتز حتى ٣٠٠٠٠ | 1779 ms | 1944 ms | **34 ms** | ×52 |

**المتوسط الهندسي للتسريع ×١٠٤.** أعد القياس: `node benchmarks/run.mjs`.
