## مِحَكّ (Mihakk)

> المِحَكّ: الحجر الذي يختبر عليه الصائغ الذهب ليعرف أصيله من مغشوشه.

يساعد الدكتور على تقييم الأعمال البرمجية، من الواجب الأسبوعي في السنة الأولى إلى مشروع
التخرج: يحلل الكود (ست لغات) والأمان وقاعدة البيانات والتقرير، ويناقش الطالب بأسئلة من
كوده تتكيف مع مستواه، ويكشف النسخ حتى بعد إعادة الصياغة، ويقترح درجة مبررة يعتمدها
الدكتور. من أهم ما فيه:

- **بصمة الفهم:** خطأ صغير يُزرع في دالة من كود الطالب نفسه، وعليه أن يجده ويصلحه خلال
  دقائق؛ التصحيح آلي لأن النظام يحتفظ بالأصل.
- **وضع الصمود:** رفع يستأنف بعد انقطاع الكهرباء أو الإنترنت، ومناقشة يتوقف وقتها أثناء
  الانقطاع، وواجهة تفتح دون اتصال.

التفاصيل والتشغيل: [README مِحَكّ](https://github.com/khalilo-cs/Final-project/blob/ccr-1a115ee7-l5go2p/README.md)

```bash
git clone -b ccr-1a115ee7-l5go2p https://github.com/khalilo-cs/Final-project mihakk
```
