# بروتوكول دراسة المستخدمين

هذا المجلد يحتوي كل ما يلزم لإجراء دراسة المستخدمين الموصوفة في القسم ١١ من وثيقة المشروع وتحليلها.

## التصميم

| البند | التفصيل |
|---|---|
| المشاركون | ٢٤–٣٠ مبتدئًا (ثانوي أو سنة أولى جامعية) بلا خبرة برمجية سابقة |
| التصميم | بين المجموعات: **أ** ترى رسائل الخطأ الرسمية فقط، **ب** ترى الرسائل + الشرح المتدرج |
| التوزيع | عشوائي متوازن (`python3 analyze_study.py assign 30` يولّد جدول التوزيع) |
| المدة | ٧٥ دقيقة للمشارك |
| الأداة | الساحة (`editors/web`) — الدروس ١–٤ ثم الدرس ٧ (إصلاح الأخطاء) |
| الخطة البديلة | إن تعذّر العدد: ٨–١٢ مشاركًا بتصميم داخل المجموعات (كل مشارك يرى الحالتين بترتيب معاكس) |

## الإجراء (لكل مشارك)

| الدقيقة | الخطوة | الأداة |
|---|---|---|
| ٠–٥ | الموافقة المستنيرة، شرح الدراسة | `consent.md` |
| ٥–١٥ | الاختبار القبلي (١٠ أسئلة) | `comprehension_test.md` |
| ١٥–٤٥ | الدروس ١–٤ في الساحة | الساحة: زر «الدروس» |
| ٤٥–٦٠ | مهمة الإصلاح: الدرس ٧ + برنامج فيه ٥ أخطاء (`tasks/مهمة_الإصلاح.ضاد`) | الساحة |
| ٦٠–٦٨ | الاختبار البعدي (الأسئلة نفسها بترتيب مختلف) | `comprehension_test.md` |
| ٦٨–٧٥ | استبيان SUS + مقابلة قصيرة (٣ أسئلة) | `sus.md` |

يسجّل الباحث لكل مشارك في `data_template.csv`: درجتي الاختبار، عدد الأخطاء المُصلَحة من ٥، زمن الإصلاح،
أعلى مستوى تلميح استُخدم، وإجابات SUS العشر.

## الفرضيات

- **ف١:** المجموعة ب تُصلح أخطاءً أكثر في زمن أقل من أ.
- **ف٢:** تحسّن الفهم (البعدي − القبلي) أعلى في ب.
- **ف٣:** درجة SUS للمنصة ≥ ٧٠ (فوق المتوسط العالمي ٦٨).

## التحليل

```bash
python3 analyze_study.py analyze بيانات.csv
```

يحسب: درجة SUS لكل مشارك ومتوسطها، ولكل مقياس: متوسط المجموعتين، اختبار t لـ Welch، اختبار Mann–Whitney U
(تقريب طبيعي)، وحجم الأثر Cohen's d. لا يحتاج مكتبات خارجية. `python3 analyze_study.py selftest` يتحقق من
صحة الحسابات على قيم معروفة.

## الأخلاقيات

- مشاركة طوعية، ويمكن الانسحاب في أي وقت دون إبداء سبب.
- لا تُجمع أسماء في ملف البيانات؛ كل مشارك برمز (م٠١، م٠٢…).
- للقُصَّر: موافقة ولي الأمر إضافةً إلى موافقة المشارك.
- يُستشار المشرف بشأن الحاجة إلى موافقة لجنة أخلاقيات البحث في الجامعة قبل البدء.
