# استبيان قابلية الاستخدام (SUS)

ضع دائرة حول الرقم: ١ = لا أوافق بشدة … ٥ = أوافق بشدة.

| # | العبارة | ١ | ٢ | ٣ | ٤ | ٥ |
|---|---|---|---|---|---|---|
| ١ | أعتقد أنني سأرغب في استخدام هذه المنصة بشكل متكرر. | | | | | |
| ٢ | وجدت المنصة معقدة أكثر مما ينبغي. | | | | | |
| ٣ | اعتقدت أن المنصة سهلة الاستخدام. | | | | | |
| ٤ | أعتقد أنني سأحتاج إلى دعم شخص تقني لأتمكن من استخدام هذه المنصة. | | | | | |
| ٥ | وجدت أن الوظائف المختلفة في هذه المنصة متكاملة بشكل جيد. | | | | | |
| ٦ | اعتقدت أن هناك الكثير من التناقض في هذه المنصة. | | | | | |
| ٧ | أتصور أن معظم الناس سيتعلمون استخدام هذه المنصة بسرعة كبيرة. | | | | | |
| ٨ | وجدت المنصة مرهقة جدًا في الاستخدام. | | | | | |
| ٩ | شعرت بثقة كبيرة أثناء استخدام المنصة. | | | | | |
| ١٠ | احتجت إلى تعلم الكثير من الأشياء قبل أن أتمكن من البدء باستخدام هذه المنصة. | | | | | |

**المقابلة القصيرة:** (١) ما أصعب لحظة واجهتها؟ (٢) هل ساعدتك رسائل الخطأ؟ كيف؟ (٣) لو غيّرت شيئًا واحدًا في المنصة، ماذا يكون؟
