# شارح أخطاء ضاد الذكي (الطبقة الثالثة)

يشرح أخطاء برامج ضاد بالعربية للمبتدئين، على أربعة مستويات تربوية متدرجة، **دون أن يمسّ حتمية المترجم**:
المترجم يكتشف الخطأ ويحدد كوده وسطره، والنموذج اللغوي يشرحه فقط.

```
dhad افحص/شغّل --json ──► خطأ منظَّم (كود، رسالة، سطر)
                              │
       docs/errors/*.md ──► موجّه نظام ثابت (قواعد + مرجع الأخطاء كاملًا) ── مخزَّن مؤقتًا
                              │
                     رسالة المستخدم: الخطأ + مقتطف مرقَّم + المستوى المطلوب
                              │
            المزود: Claude │ Ollama (محلي) │ من التوثيق (بلا شبكة)
                              │
                       حارس الجودة ──✘──► الشرح الحتمي من التوثيق
                              │✔
                            العرض
```

## المستويات

| المستوى | المحتوى | كتل الكود | يذكر السطر |
|---|---|---|---|
| ١ — ماذا يعني الخطأ؟ | إعادة صياغة مبسطة | ممنوعة | — |
| ٢ — أين المشكلة ولماذا؟ | السطر والمفهوم | ممنوعة | إلزامي |
| ٣ — مثال مشابه | مثال محلول لا يمس كود الطالب | واحدة | — |
| ٤ — كيف أصلحه؟ | تعديل سطر الطالب (يُعرض ولا يُطبَّق) | واحدة | إلزامي |

## حارس الجودة

يُرفض الشرح ويُعرض بدلًا منه شرح التوثيق إن: كان فارغًا أو غير آمن (HTML/سكربت)، أو أقل من ٨٥٪ عربية،
أو تجاوز حد الكلمات، أو خالف عدد كتل الكود المسموح، أو ذكر كود خطأ آخر، أو ذكر سطرًا غير سطر الخطأ،
أو لم يذكر السطر حين يلزم، أو كانت كتلة الكود ليست ضادًا صحيحًا نحويًا (يُتحقق بالمترجم نفسه).

## الاستخدام

```bash
pip install -e ai-explainer             # يثبّت anthropic
cargo build -p dhad-cli                  # يحتاج الأمر dhad
export ANTHROPIC_API_KEY=...             # للمزود claude

python -m dhad_explainer برنامج.ضاد --كل                  # المستويات الأربعة
python -m dhad_explainer برنامج.ضاد --مستوى 2 --مزود ollama
python -m dhad_explainer برنامج.ضاد --مزود offline --json
```

| متغير البيئة | الافتراضي | الوصف |
|---|---|---|
| `DHAD_LLM_MODEL` | `claude-opus-5-5` | نموذج Claude |
| `DHAD_LLM_EFFORT` | `low` | جهد التفكير (`low`…`max`) — الشروح قصيرة، فالمنخفض يكفي غالبًا |
| `DHAD_OLLAMA_MODEL` | `aya-expanse:8b` | نموذج محلي يدعم العربية |
| `DHAD_EXPLAINER` | `claude` | المزود الافتراضي |

تفاصيل طلب Claude: موجّه النظام مُعلَّم بـ `cache_control` (ثابت بايتًا ببايت، فتُقرأ معظم المدخلات من الذاكرة المؤقتة)،
والتفكير تكيّفي، و`fallbacks: "default"` مفعّل: إن رفض النموذج طلبًا لأسباب أمان أعاد الخادم تشغيله على نموذج بديل.
عند غياب المفتاح أو تعطل الخدمة يُعرض شرح التوثيق مع ذكر السبب، ولا يتوقف الشارح أبدًا.

## التقييم

```bash
python3 eval/run_eval.py --providers offline claude ollama
python3 eval/score_ratings.py مقيم١.csv مقيم٢.csv
```

`run_eval.py` يشغّل كل كود خطأ × المستويات الأربعة لكل مزود، ويكتب في `eval/results/`: الشروح (JSONL)، ملخص معدل
اجتياز الحارس وأسباب الرفض والزمن، وورقة تقييم بشري **مزدوجة التعمية** (المزود مخفي والترتيب عشوائي).
`score_ratings.py` يحسب متوسط الدقة والبساطة وسلامة العربية لكل مزود، واتفاق المقيّمَين (κ كوهين الموزونة).
